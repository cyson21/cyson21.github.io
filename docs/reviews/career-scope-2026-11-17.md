# 경력 문서의 담당 범위 정리

사용자 지시에 따라 이엠캐스트 경력을 개별 버그 수정 사례에서 지속적인 담당 업무로 바꿨다. 플랫폼 API·관리자 기능 개발, 2.0→3.0 전환, 비동기 처리·운영 자동화와 배포·협업으로 구성했다. 이력서·경력기술서와 웹 경력 소개의 문안을 맞췄으며, 상세 기술 사례의 데이터 모델을 경력기술서에서 분리했다. 원티드 기본 이력서에도 같은 문안을 저장했다.

이력서와 경력기술서는 각 A4 2쪽이다. 전자는 핵심 업무를, 후자는 회사별 프로젝트 맥락과 담당 범위를 설명한다. 화이트스캔의 네 프로젝트와 확인된 기간·역할을 유지했다. 개인 프로젝트와 개별 오류 수정 사례는 경력 문서에 포함하지 않는다. 같은 내용을 다시 넣지 않도록 AGENTS.md와 경력 정본에 편집 규칙을 남겼다.

로컬에서 최종 정적 빌드, 공개 안전성, 내부 링크를 확인했다. 합본 4쪽을 렌더링해 잘림·겹침을 확인했다. 변경한 인쇄 화면의 최소 브라우저 검사를 수행한다. 전체 회귀와 타입·콘텐츠 검사는 CI가 담당한다. 회사 소스나 회사 테스트는 추가로 조회·실행하지 않았다.
