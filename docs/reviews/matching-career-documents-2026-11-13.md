# 이력서·경력기술서 역할 분리와 공통 서식

- 이력서: 2쪽. 첫 쪽의 핵심 경력과 문제 해결 요약을 유지하고 개인 프로젝트 항목을 제거했다. 둘째 쪽은 이전 회사 프로젝트·학력·상세 문서 링크로 구성했다.
- 경력기술서: 3쪽에서 2쪽으로 줄였다. 회사 일반 소개와 이전 회사 프로젝트의 반복을 덜고 배치, 주문·결제, 저장 상태 재검증, 복합 식별자 네 사례를 문제·판단·수행·기여로 정리했다. 기존 경력 사실에서 내용을 선별했으며 새로운 성과 수치를 추가하지 않았다.
- 두 문서는 공통 CSS로 종이 여백, 글꼴, 본문 색, 제목·날짜·쪽 번호를 맞췄다. 웹 개인 프로젝트 페이지는 유지했다.
- PDF 각각 A4 2쪽, 총 4쪽을 PNG로 렌더링해 잘림·겹침과 가독성을 확인했다. 390px·994px에서 출력 원본의 가로 넘침이 없음을 확인했다.
- 관련 브라우저 검사 6개, 공개 안전성·내부 링크 검사를 통과했다. PDF 다운로드의 쪽 수와 문서 구조 검사도 두 파일에 적용했다.
- 공개 반영은 PR CI와 Pages 배포 성공 후 실제 경력 페이지의 두 다운로드 버튼으로 파일을 받아 배포 파일과 원본 SHA-256을 비교한다.
