# 이력서·경력기술서 기여 중심 정리 · 2026-11-10

사용자가 지원 문서에 과하게 추가된 검증 설명을 빼고 실제 경력과 기여가 드러나도록 정리해 달라고 요청했다.

- 경력기술서에서 테스트 대역, 고정 입력, DB 통합 실행·최종 QA·운영 결과 미확인과 재실행 여부 설명을 제거했다.
- 사례의 `확인` 항목은 담당한 모니터링 구현과 QA 원인 추적·호출 순서 조정 등 `기여`로 바꿨다. 데이터 변경·조회 개선은 실제 상황과 수행 내용으로 정리했다.
- 이력서와 경력기술서의 플랫폼 전환 항목은 변경 기능의 통합·회귀 테스트 보완이라는 실제 업무로 표현했다.
- 회사·기간·직급·프로젝트·기술·참여 범위는 유지했다. 새 성과 수치나 전체 성공·무재발 주장을 추가하지 않았다.
- 이번 확인은 수정 문안과 PDF 출력·공개 파일 반영에 한정한다.

출력 템플릿과 구성은 이력서 2쪽·경력기술서 3쪽을 유지한다. 기존 개인 프로젝트 설명과 공개 테스트 근거는 변경하지 않는다.

## 출력 확인

두 PDF를 생성한 뒤 전체 5쪽을 PNG로 렌더해 잘림·겹침을 확인했다. 추출 텍스트에서 과도한 검증 설명의 제거와 실제 수행 문구를 확인했고, 공개 자산·내부 링크 검사를 통과했다.
