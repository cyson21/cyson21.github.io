실무 사례

이엠캐스트 B2B 리테일 교육 플랫폼에서 맡은 백엔드 문제 해결 사례입니다. 담당 범위와 원인, 기술 선택과 수정 과정을 정리했습니다.

실무 사례 목록

  • 배치 중복 실행 제어와 누락 모니터링중복 실행은 분산락으로 제어하고, 예정 목록과 실행 기록을 대조해 누락을 찾았습니다.
  • 주문·결제의 락 경합과 커밋 순서 조정결제 전에 요청 상태를 먼저 커밋하고, 락 예외와 완료 주문의 재처리 조건을 정리했습니다.
  • 저장 직전 상태 재검증과 후속 갱신 기준 통일저장 직전 상태를 다시 조회해 설정 변경과 후속 갱신의 판단 기준을 맞췄습니다.
  • 복합 식별자로 조회·삭제·페이지 집계 기준 통일사용자·그룹 조합으로 대상을 구분하고 페이지 목록과 총건수에 같은 조건을 적용했습니다.
  • 메시지 요청 접수와 결과 처리 분리RabbitMQ 기반으로 요청 접수 응답과 후속 발송 결과를 나누는 작업에 참여했습니다.

이력서·경력기술서에서 요약한 네 사례와 메시지 처리 분리 작업을 다룹니다.
