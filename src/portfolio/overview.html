본문으로 건너뛰기

실무 사례

이엠캐스트 B2B 리테일 교육 플랫폼의 백엔드 개발·운영 중 맡은 문제입니다. 각 사례에서 담당 범위와 원인, 수정, 확인 결과를 읽을 수 있습니다.

실무 사례 목록

  • 저장 시점의 상태 재검증저장 전 현재 상태를 조회하고 후속 갱신 기준을 통일했습니다.
  • 락 경합과 트랜잭션 경계분산락과 커밋 순서, 락 오류의 제한적 재시도를 조정했습니다.
  • 배치 중복 제어와 누락 감지분산락과 예정 목록 대조를 각각 적용했습니다.
  • 복합 식별자와 페이지 집계조회·삭제·동등성의 식별 기준을 맞췄습니다.
  • 메시지 요청과 결과 처리RabbitMQ 기반 요청·결과 처리 분리에 참여했습니다.

당시 코드·테스트 정의·저장된 기록을 기준으로 작성했습니다. 직접 확인한 결과와 한계는 각 상세에 표시했습니다.
