# 경력기술서 · 읽기 문서

- 대상: src/pages/resume/career.astro 및 public/downloads/career-description.pdf.
- Mode: Read. 채용 담당자가 회사별 업무와 실무 문제 해결의 판단·근거를 읽는다.
- 승인: 2026-10-03 내용은 유지하고 impeccable로 디자인을 정리한다.
- 기존 Quiet Slate의 흰 종이·슬레이트 본문·절제된 파랑·평평한 표면을 유지한다.
- 인쇄는 A4 3쪽, 첫 쪽 회사별 업무, 이후 두 쪽에 대표 4개 사례. 개인 프로젝트는 보조 링크.
- 사례 항목명은 좁은 열에 정렬하고 480px 이하에서 본문 위에 쌓는다. 좌우 반반 카드나 장식은 추가하지 않는다.
- 문서 화면은 모바일 본문 16px, 인쇄 사례 본문 11pt를 사용한다. 문서 전용 크기는 사이트 일반 화면 타입 램프와 별개다.
- 링크 목적지·문안·담당 범위·검증 주장과 기존 이력서 PDF는 유지한다.
- 검증은 해당 문서 390·768·1280px, PDF 3쪽과 본문/푸터 간격, 공개 파일·내부 링크로 한정한다. 추가 회귀는 개인 GitHub CI에 맡긴다.
- 사용자 요청 전 로컬 미리보기·문서 패널을 열지 않는다.
